# SNR柱状图交互功能实现

## 功能说明

为监测模块的SNR柱状图（`MultiSignalBarWidget`）添加了鼠标悬停提示功能。当用户鼠标悬停在任何柱子上时，会显示一个包含以下信息的tooltip：

- **卫星号**（如 G01, R02, E03）
- **信号标识**（如 L1, L5, E5b）
- **SNR值**（精确到0.1 dB-Hz）

## 实现细节

### 1. 核心改动位置
文件：`ui/monitoring/widgets.py` - `MultiSignalBarWidget` 类

### 2. 主要改进

#### 初始化阶段 (`__init__`)
- 添加 `bar_data_map` 字典来存储每个bar对应的数据（卫星号、信号、SNR值）
- 添加 `tooltip_annotation` 变量来管理当前显示的tooltip
- 连接matplotlib的 `motion_notify_event` 事件，用于监听鼠标移动

#### 数据更新阶段 (`update_data`)
- 在绘制每个bar时，同时将其关联有效信息存储到 `bar_data_map`
- 结构：`{bar_object: {'satellite': '卫星号', 'signal': '信号', 'snr': SNR值}}`

#### 交互处理阶段
新增三个方法：

1. **`_on_mouse_move(event)`**
   - 响应鼠标移动事件
   - 通过边界框碰撞检测判断鼠标是否在某个bar上
   - 找到bar时调用`_show_tooltip()`，否则调用`_hide_tooltip()`

2. **`_show_tooltip(event, bar_info)`**
   - 创建tooltip annotation对象
   - 显示卫星号、信号、SNR值三行信息
   - 使用黄色背景（浅色主题）或浅黄色背景（暗色主题），便于识别
   - 自动定位鼠标位置，并偏移10像素避免遮挡

3. **`_hide_tooltip()`**
   - 移除当前显示的tooltip annotation对象
   - 在鼠标离开bar或图表区域时调用

### 3. 技术细节

**碰撞检测方法**：
```python
# 简单高效的矩形碰撞检测
x = bar.get_x()
width = bar.get_width()
height = bar.get_height()

if x <= mouse_x <= x + width and 0 <= mouse_y <= height:
    # 鼠标在bar内
```

**Tooltip样式**：
- 字号：9pt（小号字体，不影响图表观看）
- 背景：黄色系，半透明（alpha=0.9）
- 文本颜色：与主题配色对应
- 位置：相对鼠标偏移10像素

## 使用体验

### 普通信号稀疏（信号+卫星数量少）
- 柱子宽度正常（保持原有宽度）
- 鼠标悬停时清晰显示信息

### 信号频点特别多的场景
- 柱子自动变细，保证最小宽度0.05个单位
- 鼠标悬停仍能轻松识别柱子，获取精确数据
- **解决了原有问题**：用户不再需要费力查看细小的柱子，直接悬停即可获得所有信息

## 性能考量

- 事件处理采用轻量级的矩形碰撞检测，O(n)复杂度
- 仅在鼠标移动时执行，不影响图表重绘性能
- Tooltip使用annotation对象，matplotlib原生支持，效率高

## 兼容性

- ✅ 适配深色主题和浅色主题
- ✅ 与现有的图表缩放、平移等交互兼容
- ✅ 不依赖额外的第三方库
